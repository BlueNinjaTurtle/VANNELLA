Tu es un ingénieur IoT et Développement Web expert.

Je réalise un projet tutoré universitaire appelé VANNELLA.

Objectif :
Créer un prototype Smart Campus permettant la gestion intelligente des salles universitaires.

Architecture du projet :

1. Une application Web PHP/MySQL déjà fonctionnelle sous XAMPP.
2. Une base de données contenant les salles.
3. Une carte Arduino UNO avec communication série vers un script Python.
4. Le script Python écoute la communication série et envoie des requêtes HTTP vers le serveur Apache local.
5. Le but n'est PAS une production réelle mais une démonstration fonctionnelle pour soutenance.

Important :
- Pas de cloud.
- Pas de vrai WiFi externe.
- Tout fonctionne en LOCALHOST sur une connexion série.
- L'Arduino UNO agit comme capteur IoT avec Python comme intermédiaire réseau.
